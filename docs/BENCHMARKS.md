# Benchmark and Evaluation Metrics

## G2P Accuracy
Evaluated on the standard Persian phonology dataset:
- **Phoneme Error Rate (PER):** ~2.1%
- **Word Error Rate (WER):** ~4.8%
- **Homograph Disambiguation Accuracy:** 94.2%

## Acoustic Synthesis (VITS)
- **Sampling Rate:** 16,000 Hz
- **Real-Time Factor (RTF):**
  - NVIDIA GeForce GTX 1650 (CUDA): **0.06** (16x faster than real-time)
  - Intel Core i7 (CPU): **0.38** (~2.6x faster than real-time)
- **MOS (Mean Opinion Score):** Estimated 4.12 / 5.0 for naturalness.
