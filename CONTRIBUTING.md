# Contributing to Persian TTS

We welcome contributions to the Persian Text-to-Speech project!

## How to Contribute
1. **Fork the Repository** and clone your fork locally.
2. **Create a Feature Branch:** `git checkout -b feature/your-feature-name`
3. **Write Unit Tests:** Ensure all tests pass under `tests/`.
4. **Follow PEP 8 Style Guidelines.**
5. **Submit a Pull Request** describing your changes and motivations.

## Reporting Issues
Please open an issue describing the bug, steps to reproduce, and environment details.
